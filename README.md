# Portafolio · Lina Prieto

Sitio publicado con GitHub Pages.

## Cómo subir imágenes

1. Entra a la carpeta `img/` y luego a la del caso (por ejemplo `img/cup/`).
2. Botón **Add file → Upload files**, arrastra la imagen y dale **Commit changes**.
3. El nombre del archivo tiene que ser exactamente el de la lista. Sirve `.png`, `.jpg` o `.webp`.
4. En 1–2 minutos aparece en el sitio.
